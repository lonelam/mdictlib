## Commands

```sh
export MDICT_CORPUS_DIR=/absolute/path/to/manifest-verified-corpus

cargo test --locked --release --all-features --test local_corpus -- \
  --ignored --nocapture
cargo test --locked --release --all-features --test local_sample -- \
  --ignored --nocapture
cargo test --locked --release --all-features --test local_lookup_regression -- \
  --ignored --nocapture

cargo build --locked --release --all-features --example bench_local

manifest="$MDICT_CORPUS_DIR/mdictlib-corpus.tsv"
mdx_selector="$(awk -F '\t' '$2 == "mdx" && $5 == 293877 { print $1; exit }' "$manifest")"
mdd_selector="$(awk -F '\t' '$2 == "mdd" && $5 == 160806 { print $1; exit }' "$manifest")"
test -n "$mdx_selector"
test -n "$mdd_selector"

env MDICT_BENCH_FILTER="$mdx_selector" MDICT_BENCH_WARM_RUNS=100 \
  MDICT_BENCH_THREADS=8 /usr/bin/time -l \
  target/release/examples/bench_local > benchmark-mdx.tsv
env MDICT_BENCH_FILTER="$mdd_selector" MDICT_BENCH_WARM_RUNS=100 \
  MDICT_BENCH_THREADS=8 /usr/bin/time -l \
  target/release/examples/bench_local > benchmark-mdd.tsv
env MDICT_BENCH_WARM_RUNS=100 MDICT_BENCH_THREADS=8 /usr/bin/time -l \
  target/release/examples/bench_local > benchmark-full-corpus.tsv
```

The selectors above derive the deidentified representative paths from the
manifest facts recorded on this page; they do not disclose private filenames.

All seven corpus files opened under the default limits. The largest observed
accounted peak (20.43 MB in the representative runs) and full-corpus process
peak (107,724,800 bytes) leave substantial headroom below the 1 GiB aggregate
default while still bounding hostile declarations before reads and
allocations.

The final `0.1.0` candidate reran the three ignored release gates in 16.41 s
(`local_corpus`), 15.93 s (`local_sample`), and 68.73 s
(`local_lookup_regression`). The last run streamed every MDD payload and checked
all seven key and record/resource digests above.
